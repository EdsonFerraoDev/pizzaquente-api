# PizzaQuente API 🍕

API REST para gerenciamento de Pizzaria desenvolvida com Spring Boot.

## Tecnologias
- Java 17
- Spring Boot 3
- Spring Data JPA
- MySQL

## Endpoints
- `GET /pizzas` - Lista todas as pizzas
- `POST /pizzas` - Cadastra nova pizza
- `GET /clientes` - Lista todos os clientes
- `POST /clientes` - Cadastra novo cliente

## Como Executar
1. Clone o projeto
2. Abra no VS Code ou IntelliJ
3. Execute a classe `PizzaquenteApplication`
